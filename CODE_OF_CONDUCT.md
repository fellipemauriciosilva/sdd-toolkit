# Código de Conduta

Esperamos que todas as pessoas participantes do projeto ajam com respeito, boa-fé e profissionalismo.

Não são aceitos assédio, discriminação, ameaças, ataques pessoais, exposição de informações privadas ou comportamento deliberadamente perturbador.

Mantenedores podem remover conteúdo, encerrar discussões ou limitar a participação quando isso for necessário para proteger a comunidade. Relatos devem ser enviados de forma privada conforme [SECURITY.md](SECURITY.md) quando envolverem risco, abuso ou informação sensível.

O contato e o responsável inicial pelo enforcement estão indicados em
[MAINTAINERS.md](docs/MAINTAINERS.md). Quando houver conflito de interesse, o relato
deve solicitar encaminhamento para outro mantenedor.

Este código se aplica a issues, pull requests, Discussions, revisões, mensagens e demais espaços oficiais do projeto.
