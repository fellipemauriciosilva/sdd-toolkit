# Caso 01 — React greenfield

Projeto consumidor `example-store-web`, React com npm e `package-lock.json`.
Não existe framework E2E. A spec aprovada pede validar login e inclusão de um
produto no carrinho. O comando local é `npm run dev` e a aplicação informa
readiness em `http://127.0.0.1:3000/health`.

Execute o agente em modo `--plan`. O usuário ainda não aprovou instalação de
dependências pela rede.
